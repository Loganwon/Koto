# Koto 内嵌助手当前路线

更新：2026-10-22。当前实现说明以 [Companion](../../companion/README.md) 和 [执行边界](../../companion/design/agent-runtime-next.md) 为准。
此前浮窗、证书待授权及旧 M0–M4 进度描述移入 [2026-10-16 历史规划](../archive/companion-roadmap-20261016.md)。

| 阶段 | 当前状态 | 后续验收 |
| --- | --- | --- |
| Word/WPS 文字接入 | 已有原生基础流程记录 | 新执行器变更后仍须分别真机复验 |
| 任务验收与来源单位 | 已接入代码，定向回归与真实模型复测 | 不漏页数、币种、来源、合计与状态限定 |
| 草稿修复及交付修订 | 已实现有界修复、当前稿、Word/PPT 段落修订 | 连续多文件交付及反馈，不影响其他内容 |
| 稳定恢复 | 同进程停止/继续有基础；重启绑定未完成 | 重连核对文档及结果后恢复原任务，不重放不确定写入 |
| 通用任务与更多宿主 | 部分文件工具，协议入口仍属设计 | 先扩大未见任务与质量评测，再扩 MCP、沙箱、Excel/PPT 原生新版 |
| Mac | 未验收 | Word 与 WPS 分别确认安装及接口，再执行同等真机验收 |

每阶段以完整任务的事实正确性、约束保持、反馈连贯性和真实交付为依据。程序回归、模型文件测试、真实 Office/WPS 验收分别记录。
