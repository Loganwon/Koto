围绕真实文件

不是泛聊天框，而是一个能继续把事做完的文件工作台。

不同格式需要不同的查看和编辑方式。Koto 把常见办公文件放入同一个工作区：先处理内容，再继续完成文件中的修改、整理和交付。

具体可用操作取决于文件格式和任务要求；复杂任务会以当前文件、目标和执行结果为准。

DOC

文档与长文本

阅读、改写、批注、对照和继续编辑。

XLS

表格与数据

查看工作表、整理数据、分析结果与图表。

PPT

演示与汇报

整理幻灯片内容，并继续修改材料。

PDF

资料与参考文件

在工作区阅读、提炼和连接后续任务。

产品原则

把控制权放回你的工作流，而不是藏在一次回答里。

我们更在意“是否能回到当前文件继续工作”，而不是用无法验证的功能清单制造复杂感。

01

文件是第一界面

文件树、编辑器与当前任务在一处出现，让每次交互都能找到对应的工作对象。

02

过程保持可读

把当前步骤、提案和待执行动作呈现出来，避免把一整个文件任务压缩成一句模糊结论。

03

模型服务于任务

根据你的设置使用本地或云端能力；无论选择什么，文件工作区都是协作的起点和终点。
