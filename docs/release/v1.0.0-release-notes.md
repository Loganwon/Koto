# Koto v1.0.0 — 首个稳定公开版

Koto v1.0.0 是面向 Windows 用户的首个稳定公开版本。当前安装包、便携版、发布清单和 SHA-256 校验文件于 **2026-07-14** 完成构建与上传。

## 这一版带来了什么

- 本地文件工作区：在同一界面管理文件、直接编辑，并让 AI 基于当前文件和选区协作。
- 可见的文件任务过程：展示执行步骤、目标文件、修改提案和最终写回结果。
- Office 文件工作流：覆盖 DOCX、XLSX、PPTX、PDF 以及常用文本和数据文件。
- 本地与云端模型选择：根据任务和用户设置切换模型路径，文件工作区保持一致。
- 首次使用引导：改善空白状态、模型选择、任务进度和完成结果的表达。

## 稳定性与安全性

- 完成 Windows 安装版和便携版的打包、启动、健康检查与端到端验证。
- 加固文件任务的目标识别、写回验证、只读安全和失败报告。
- 锁定并审计运行时依赖，补充发布清单和 SHA-256 校验文件。
- 通过 CI、CodeQL、Docker 启动验证以及发布级回归测试。

## 下载选择

- `Koto_v1.0.0_Setup.exe`：推荐大多数 Windows 用户使用的安装版。
- `Koto_v1.0.0_Windows.zip`：免安装便携版，解压后运行。
- `Koto_v1.0.0_SHA256SUMS.txt`：用于核对下载文件完整性。
- `Koto_v1.0.0_release-manifest.json`：包含发布资产的结构化版本和哈希信息。

## 校验下载文件

在 PowerShell 中运行：

```powershell
Get-FileHash .\Koto_v1.0.0_Setup.exe -Algorithm SHA256
Get-FileHash .\Koto_v1.0.0_Windows.zip -Algorithm SHA256
```

将结果与 `Koto_v1.0.0_SHA256SUMS.txt` 中的值比较。
