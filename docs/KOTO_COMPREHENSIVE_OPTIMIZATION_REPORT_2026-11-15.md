## Agent 设计

继续使用一个 Kernel、ToolCatalog 和 TaskLedger。模型负责目标理解、规划和工具选择；安全作用域、文件事务、持久事件、恢复、验证和界面状态由程序负责。Office/WPS 保留宿主适配器身份，原版工作台独立运行。

公开生成内容可以立即显示；完整工具参数校验后才执行。任务成功由实际产物与最终验证决定，消息生成完不等于文件已保存。读回、版本与作用域冲突均保留原始证据。

任务断线只是失去观看连接，GET 恢复不启动新执行；取消需到真实安全边界才确认。已提交副作用如实保留，未知副作用先核实。浏览器动作使用同库持久状态和投递凭据，不再依赖单个进程的内存 Map。

## 固定任务评估口径

24 个固定办公任务，每项三次，覆盖读取、修改、生成追改及故障恢复。评分独立重开实际文件，核对数字/来源、修改范围、格式、额外产物和重复写入；生成后追改的每个 phase 都必须有正确终态。

故障任务的通过指按预期拒绝且保留原文件，或恢复后只写一次，不把注入保存失败说成保存成功。任务文本和验收脚本均记录哈希；生产或验收脚本运行中漂移的轮次不作为最终冻结成绩。

脚本模型用于验证程序执行和文件效果。真实模型质量单独统计，不能把这些工程任务检查、单元测试或 fixture 的首字时延当作真实 AI 能力或服务时延。

最终冻结源码执行 72/72，通过后再用重新编译的原生工具运行相同 72 次检查，仍为 72/72。源码最终轮的提示词、验收器及源码快照前后哈希一致，记录 198 次脚本模型调用、105 次工具调用；实际 provider token 和费用未测量。早期调试候选既包含真实缺陷也包含验收器修正，不用于宣称模型能力提升百分比。

## 明确边界

1. 文档语义补丁保留文本块数量，拒绝跨不兼容的单元格/列表层级、行内原子对象和歧义锚点，不声称任意文档结构插删。
2. 受保护结构的计数下降检测不代表计数相等即任意 OOXML 内容和像素版式完全保真。复杂列表的层级、起始编号和重启语义需另外核对；不能将基本列表文字保存扩展为所有高级编号保真。另存副本保留源文件，但不自动补回导出器不支持的复杂对象。
3. 撤销要求同一个存活编辑器和完整版本一致；重载后的过期令牌明确拒绝。持久动作去重也不等于所有未保存编辑器状态可透明跨重启恢复。
4. XLSX/PPTX/PDF 继续使用原格式工具和质量门；没有另建编辑器或万能格式转换器。Ollama 工具轮次仍保留原非流式兼容边界。
5. 本轮真实模型唯一限额连接探针因 DNS/网络错误未取得有效响应；实际 token 和费用未测量，后续 live 任务没有用 fixture 冒充。
6. 正常 HTTP 浏览器检查因没有可用 browser surface 受阻；普通本地 TCP 健康请求也返回 WinError10013。未使用 file URL、替换 host 或其它路径绕过限制，真实浏览器视觉/交互未验收。
