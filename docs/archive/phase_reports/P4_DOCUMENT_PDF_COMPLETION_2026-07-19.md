# P4 文档审阅与 PDF 可靠性完成报告

完成日期：2026-07-19

## 结论

P4 已完成。DOCX 批注/修订和 PDF 查看批注、页面操作、Office 转换、水印清理已纳入稳定功能清单，并由真实浏览器语料、产物重开验证和架构预算共同守门。

稳定功能：

- `docx.edit-review`
- `pdf.view-annotate`
- `pdf.page-operations`
- `pdf.convert`
- `pdf.remove-watermark`

## 已消除的根因

- DOCX 审阅卡片由无限 DOM 改为最多 120 项的窗口渲染；完整索引、总数、导航和无障碍位置仍覆盖全部批注。
- 批注定位排除紧凑布局中的 AI 覆盖层，并补足滚动轨道宽度，窄窗口下不再被面板遮挡或无法点击。
- PDF 文本定位使用 NFKC、大小写及标点/空白容错，同时保留 PDF.js 原始字符坐标映射；跨页选择会明确拒绝。
- PDF 批注保存延迟释放 Blob URL，避免 WebView2 或慢下载得到失效链接；缩放前后使用统一 PDF 归一化坐标。
- PDF 页面操作严格校验页码、旋转角度和非空输出，不再静默跳过并返回无效果文件。
- 水印清理区分“已移除支持的水印”和“未检测到支持的水印”；无改动时不再伪造可下载结果。
- 技能市场的 GitHub 中心、文件树的路径/搜索规则已从主模块拆出，P4 不以抬高架构预算换取放行。

## 性能与语料门槛

- DOCX：500 条原生批注语料，初始审阅卡 DOM 不超过 120；就绪时间不超过 20 秒；最大长任务不超过 1500 毫秒；第 500 条可直接导航并获得焦点。
- PDF 批注：真实文本选择、高亮、自由文本、150% 缩放一致性、保存、重传和批注位置复核；归一化位置容差 0.004。
- PDF 页面操作：真实拖拽重排、旋转、删除、下载、重传和页数复核。
- PDF 转换：DOCX/XLSX/PPTX 通过 UI 下载，并分别使用 `python-docx`、`openpyxl`、`python-pptx` 重开验证语义内容。
- PDF 水印：真实重复斜向水印清理、无水印 no-op 分支、PyMuPDF 文本与渲染像素复核。
