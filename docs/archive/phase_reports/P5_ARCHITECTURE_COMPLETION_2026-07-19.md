## 已完成的架构收敛

- 删除双重 LLM client 兼容层，以 `app/core/llm/runtime_gateway.py` 和 `web/runtime_context.py` 作为唯一运行时边界。
- 拆分后端与前端超大模块；所有生产文件低于 2000 行，所有 `web/src` 非测试 TypeScript 文件不超过 1000 行。
- 将扩展中心统一为 Addon/能力面板，移除旧 Skill 市场、社区、创建、绑定、提示词编辑及前端全局别名。
- 删除已经断连的 Skill API、Macro API、蒸馏 API、LoRA、ShadowTracer、Skill 映射和相应打包默认文件。
- 清除测试中的旧模块导入、旧字段、旧页面、旧 JSON 以及“文件不存在就跳过”的伪覆盖，避免废弃系统被测试反向复活。
- `TaskClassifier` 的重量级本地分类依赖改为显式启用，首个文件任务不再无条件加载 Transformers。
- 删除仅用于一次性迁移的 P5 改写脚本，避免它们被误运行后再次破坏源码。
