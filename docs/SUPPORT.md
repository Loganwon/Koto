# Koto 支持与反馈

## 获取帮助

请先确认你使用的是 [最新稳定版](https://github.com/Loganwon/Koto/releases/latest)，
然后查看 [用户指南](USER_GUIDE.md) 的首次使用和文件安全说明。仍无法解决时，
请在 [GitHub Issues](https://github.com/Loganwon/Koto/issues/new/choose) 提交问题。

## 提交问题前的快速检查

1. 重启 Koto 后重试一次相同任务。
2. 确认模型已配置、网络或本地模型服务可用。
3. 将任务缩小为一个文件和一句清晰指令，确认问题是否仍出现。
4. 检查任务报告中的失败步骤与产物路径。

## 一份高质量反馈应包含

- Koto 版本、Windows 版本和发生时间；
- 你希望发生什么，以及实际发生了什么；
- 可复现的最短步骤、文件类型和是否允许写入；
- 错误提示或相关 `logs/` 文件中与该时间对应的片段；
- 截图前请遮住 API Key、访问令牌、个人信息和商业敏感内容。

请不要上传 `config/deepseek_config.env`、任何 API Key、完整私人文档或含有
敏感内容的聊天历史。可使用替代文件或删减后的示例复现问题。

## 安全问题

请不要在公开 Issue 中披露安全漏洞、密钥或可被直接利用的细节。请通过仓库主页
提供的维护者联系方式进行私下沟通，并附上最小复现和影响说明。

## 支持范围

Koto 的稳定版重点支持 Windows 下载包、聊天、文件分析、文档生成与工作区任务。
模型供应商可用性、网络连通性和第三方 API 额度由对应服务负责。AI 生成结果需由
用户审核；Koto 不替代专业的法律、医疗、财务或安全判断。
